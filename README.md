# 도배 견적 계산기

모바일용 도배 견적 계산기입니다.

## 적용 단가
- 소폭: 15,000원/롤
- 광폭: 21,000원/롤
- 실크: 44,000원/롤
- 인건비: 1인 260,000원
- 초배작업: 평당 10,000원
- 식비: 인당 20,000원
- 폐기물 처리: 50,000원
- 실크 부자재: 100,000원

## 도배 롤수 기준표

| 평수 | 천장 | 소폭 | 광폭 | 실크 |
|---|---|---:|---:|---:|
| 25평 | 포함 | 38 | 20 | 17 |
| 25평 | 제외 | 32 | 17 | 14 |
| 33평 | 포함 | 48 | 26 | 23 |
| 33평 | 제외 | 40 | 22 | 19 |
| 45평 | 포함 | 65 | 35 | 31 |
| 45평 | 제외 | 54 | 29 | 26 |
| 51평 | 포함 | 80 | 44 | 38 |
| 51평 | 제외 | 66 | 37 | 32 |

평수·벽지·천장 선택에 따라 위 기준표의 롤수가 자동으로 적용되며, 롤수는 직접 수정할 수도 있습니다.

## GitHub Pages
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. `main` / `/ (root)`로 저장합니다.
4. 생성된 GitHub Pages 주소로 접속하면 됩니다.

`manifest.json`, `sw.js`, PNG 아이콘이 포함되어 있어 안드로이드 Chrome에서 홈 화면에 추가하면 앱처럼 실행할 수 있습니다.
